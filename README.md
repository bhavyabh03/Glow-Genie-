Glow Genie✨


Your Ritual, Your Glow

GlowGenie is a beauty-tech web experience designed to create personalized skincare and haircare rituals through interactive quizzes and curated recommendations. 
Blending luxury-inspired aesthetics with intelligent personalization, GlowGenie transforms self-care into an immersive digital experience. 💖


What GlowGenie Does

Creates personalized skincare and haircare experiences 🌸

Recommends products tailored to individual concerns 🧴

Provides working product links for recommended items 🛍️

Generates curated morning and night routines 🌙

Suggests ingredient-focused beauty guidance 💧

Offers interactive quiz-based personalization 🎀

Generates customized beauty insights and recommendations ✨

Matches users with routines aligned to their goals 💫

Features elegant glassmorphism-inspired interface elements 🌸

Includes animated floating backgrounds and immersive visuals ☁️

Enhances self-care through a modern beauty-tech experience 💕

Provides a calming and aesthetically curated user interface 🌷

React.js
Vite

Experience

GlowGenie features interactive beauty flows, animated visuals, floating background effects, personalized recommendation systems, clickable product recommendations, and a responsive luxury-inspired interface designed to make digital self-care feel immersive and intuitive.
